# Lifeline Care Center – Nursing Care and Caregiver Booking System

## Project Overview

Lifeline Care Center is a web-based nursing care and caregiver booking system developed as a group project. The system aims to connect individuals and families who require nursing care and caregiving services with professional caregivers.

The platform provides a centralized environment where users can explore caregiving services, find caregiver information, and manage care-related bookings. It also includes administrative functions to manage caregivers and staff.

## Project Objectives

- Develop a web-based platform for nursing care and caregiver services.
- Connect clients with professional caregivers.
- Allow users to search for caregiver information.
- Provide a convenient booking process.
- Support user and caregiver management.
- Provide administrative facilities for managing the system.

## Main Features

### 1. User Management
- User registration and login.
- User welcome page.
- User profile management.
- Access to caregiving services.

### 2. Caregiver Services
- View available caregiving services.
- Search for caregiver information.
- View caregiver profiles.
- Access caregiver qualifications, experience, and availability information.

### 3. Booking Management
- Submit caregiver booking requests.
- Manage care-related booking information.
- Support scheduling-related information.

### 4. Feedback and Reviews
- Feedback section for users.
- Review and rating functionality described in the system design.

### 5. Admin Management
- Admin login and dashboard.
- Manage caregivers.
- Add staff members.
- Manage relevant system information.

### 6. Informational Pages
- Home
- About Us
- Services
- FAQ
- Contact Us
- Feedback

## User Roles

The system is designed around the following user roles:

### Client / User
- Register and log in to the system.
- Explore caregiving services.
- Search for caregiver information.
- View caregiver profiles.
- Submit booking requests.
- Manage personal information.

### Caregiver
- Maintain caregiver-related information.
- Provide qualifications and experience details.
- Provide availability information for caregiving services.

### Administrator
- Access the administrative dashboard.
- Manage caregiver information.
- Add and manage staff members.
- Oversee relevant system information.

## Database Design

The system uses a MySQL database to manage information related to the caregiving service platform.

The database design includes entities related to:

- Users
- Caregivers
- Bookings
- Payments
- Schedules
- Reviews

The database structure was designed to organize system information and support the main operations of the application.

## System Design
